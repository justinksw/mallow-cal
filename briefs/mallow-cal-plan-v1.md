## 目的

数人の「予定あり（忙しい）」日を一枚のカレンダーで見せて、活動を組める日が分かること。みんな空いている日は一目で分かること。

## 決定（Justin 2026-11-15）

- UI 言語: **繁体字中国語**（ボタン・見出し・月名・曜日・説明）
- 人名は **本名のまま** 出す。アイコンだけ動物
- 月表示はまず **2026年12月** と **2027年1月**
- カレンダーに **Justin は入れない**（この5人だけ）
- リポジトリ名: `mallow-cal`
- デザイン: 幼稚園スタイル、ピンクの可愛い綿菓子（棉花糖）風
- 動物の顔: Google スプレッドシート／ドキュメントの匿名ユーザーに出る、色つきのシンプルな動物アイコンの感じ。ただし **Google の画像・公式素材は使わない**（Celine がオリジナルで描く）
- データは **CSV ひとつ**。予定の更新は CSV を直して GitHub に保存するだけ
- Celine が先にアイコンとスタイルを出し、Justin が見てから次へ
- Jessie のページは、**違うスマホの画面サイズ・比率**でも使えること（幅だけなく縦横比も）

## v1 の範囲

- 静的な GitHub Pages。ログイン・サーバなし
- ブラウザが `data.csv` を読んでカレンダーを描く。データ更新にビルドは不要
- タイムゾーン: Asia/Hong_Kong
- 予定は終日。「開始日〜終了日」の期間と、「毎週土曜」のような繰り返しの両方を CSV で書ける
- 日付は両方含む
- 同じ日に複数人が重なったら、動物アイコンを並べる
- モバイル優先。デスクトップでも壊さないが、電話が本拠

## v1 外

## CSV（案）

1ファイル。Justin が後から行を足すだけで人が増えても動くこと。サンプルは `data/sample.csv`。

```csv
name,start,end,repeat
Gordon,2026-12-27,2027-01-09,
Winnie Wong,,,Sat
Winnie Wu,2026-12-14,2026-12-20,
Kami,2027-01-02,2027-01-02,
Nicol,2026-12-20,2026-12-27,
```

- `start` / `end` は ISO 日付。1日だけなら同じ日を両方に書く
- `repeat` が空なら期間だけ。`Sat` は毎週土曜（必要なら後で他の曜日も足せる形）
- 列名は英語のまま（ファイルを触る人用）。画面上の文言は繁中
- 動物の割り当ては CSV に書かない。名前から安定して決める（見た目はランダム、リロードや CSV 更新で同じ人の動物が変わらない）

## 動物アイコン

- Celine がオリジナルの動物の顔を描く。円形、平坦、色がはっきり、細部を増やしすぎない。Google の匿名動物アイコンの「感じ」に寄せる
- 今の5人分に加え、あとから CSV で人が増えても足りるよう、少し多めのセットにする
- モックでは5人への割り当てを仮に決めて見せてよい。本番の割り当て規則は Jessie（名前から安定）
- 画面には本名を出し、「Anonymous …」のラベルは使わない

## 画面（情報だけ。ピクセルは Celine）

- 単一ページ。2026年12月と2027年1月が見える（電話では重ねてスクロールでも、月を切り替えても可。Celine が決める）
- 年が分かること（12月は2026、1月は2027）
- 凡例: 動物アイコン＋本名
- 予定ありの日に、その人の動物が乗る
- みんな空いている日は、色や目印だけで終わらせず、予定ありの日とはっきり違うこと
- 曜日の始まりは、香港の電話カレンダーでよくある週日起点でよい
- 文言は短い繁中。英語スローガンなし。AI 臭いコピーなし

## 改正 2026-11-15（v3 punch。Justin t1278u）

表示名案「棉花糖日曆」は使わない（v2 で確定。タブは中立の「日曆」のみ可）。

追加の Substance:

1. **平日 Dim。空ける日は土曜・日曜と香港の公眾假期。** 公眾假期でない月曜〜金曜は薄くする。「空」は、空ける日かつ5人とも個人予定がない日だけ。公眾假期でない平日は「空」にしない。
2. 表示期間内の公眾假期（GovHK 2026 / 2027）: 毎週日曜、2026-12-25 聖誕節、2026-12-26 聖誕節後第一個周日、2027-01-01 一月一日。人の予定は従来どおり CSV ひとつ。假期は人の CSV に書かない。
3. この窓で「空」になる日: 12-06、12-13、01-10、01-17、01-24、01-31。
4. **連続する個人の予定は、日をまたぐ標注**（同じ印を毎日繰り返さない）。毎週土曜は連続ではないので1日ずつ。Gordon の帯は月をまたぐ。
5. **凡例（頭像＋本名）は隠せる。** カレンダー上の頭像はタップで本名が pop する。

成功条件の補足: 空き日は「週末・公眾假期のうち、みんな空いている日」が一目で分かること。連続予定はまたぎで読め、凡例を隠しても名前に辿れること。
